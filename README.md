# BorrowHub

BorrowHub is a MERN stack web application that allows users to lend and borrow items within their local community. Users can list items, find nearby available items, send borrow requests, and manage borrowing transactions.

## Features

* User registration and login
* JWT authentication
* Add and manage items
* Search and view available items
* Location-based item discovery
* Send and manage borrow requests
* Borrowing and lending management
* Transaction management
* User reviews and ratings
* User profile management

## Tech Stack

**Frontend**

* React.js
* Vite
* Tailwind CSS
* React Router
* Context API
* Axios

**Backend**

* Node.js
* Express.js
* REST APIs
* JWT
* bcrypt

**Database**

* MongoDB
* Mongoose
